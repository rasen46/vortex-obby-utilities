# vortex-obby-utilities
a bunch of obbying utilities for a game named "Vortex"

## Current Releases
| Name | Description | Compatitble with X.X.X |
| --- | --- | --- |
| Alljumper | Gives you abilities checkpoint a position | 0.10.1 |
| Noclip | Gives you abilities to fly around | 0.10.1 |
| Alignment Keys | Attempts to recreate the previously built in <> keys | 0.10.1 |
| Toolkit | Everything in here inside one single script | 0.10.1 |

## Installation (.luau files)
1. open the file you want
2. ctrl a (or just select all the contents in the file) and copy it
3. open vortex studio 
4. create a new **local script** under **StarterPlayerScripts**
5. paste the contents into the script
6. and you're done :scream:

## Installation (.vrtx files)
1. download the file you want form releases
2. open vortex studio and go to the place you want the file
3. under the **file** tab, click import project
4. after successfully importing the project, drag the script into **StarterPlayerScripts**

## Additional Notes
these scripts are not intended for production (meaning that these scripts are potentially written in a way that is not suitable for a public release)
